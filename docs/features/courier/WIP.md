# Courier future work

This file is a backlog only. It does not authorize implementation and does not define API routes, database fields, statuses, providers, or offline behavior.

Potential future work includes:

- performance and delivery metrics;
- offline task support and synchronization;
- safety/SOS reporting;
- earnings and goal views;
- tips and feedback; and
- other capabilities approved by the project team.

Each item requires a revised Courier feature specification, an approved `/api/v1/courier/...` contract, shared schema/transition rules, privacy requirements, and integration tests before it can be implemented. Do not assume SQLite, a map provider, push provider, payment provider, or storage vendor from this backlog.
